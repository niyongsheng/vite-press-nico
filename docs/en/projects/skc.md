# SKC - Smart Key Cabinet Management System

## 📋 Project Overview

**SKC (Smart Key Cabinet)** is an enterprise-grade smart key cabinet management solution designed for key management needs in modern offices, hotels, apartments, schools, and similar venues. Leveraging IoT technology, the system pairs smart hardware with a software platform to deliver secure, efficient, and intelligent key storage and access services.

### 🎯 Key Features
- **Intelligent Management**: AI-based identification, automatic assignment, smart alerts
- **Secure & Reliable**: Multi-factor authentication, full operation traceability, anomaly alarms
- **Multi-Scenario Support**: Works across offices, hotels, apartments, schools, and more
- **Real-Time Monitoring**: 24/7 monitoring, status tracking, remote management
- **Data Analytics**: Usage statistics, efficiency analysis, smart reporting

## 🚀 Core Feature Modules

### 1. Key Management
- **Key Registration**: Batch import, tag management, categorized archiving
- **Smart Assignment**: Intelligent key assignment algorithm based on permissions and demand
- **Status Tracking**: Real-time tracking of key location, usage status, and return time
- **Lifecycle Management**: Full lifecycle management from warehousing to disposal

### 2. User Management
- **Identity Authentication**: Supports card swiping, fingerprint, facial recognition, mobile NFC, and more
- **Access Control**: Fine-grained permission management with role- and department-based access
- **User Profiles**: Complete user information management with full operation history
- **Visitor Management**: Temporary visitor access request and approval workflows

### 3. Access Management
- **Smart Access**: One-touch access, scheduled access, batch access
- **Booking System**: Advance booking, time-slot management, conflict detection
- **Return Reminders**: Smart return reminders, overdue alerts, automatic recall
- **Exception Handling**: Lost key reporting, emergency handling, contingency plans

### 4. Security Monitoring
- **Real-Time Monitoring**: 24/7 video surveillance, status monitoring, anomaly detection
- **Security Alerts**: Unauthorized access, abnormal operations, system fault alerts
- **Operation Logs**: Complete operation records, audit trails, compliance reports
- **Emergency Response**: Emergency handling, remote locking, safe mode

### 5. Data Analytics
- **Usage Statistics**: Key usage frequency, peak hours, user behavior analysis
- **Efficiency Analysis**: Access efficiency, wait times, system performance analysis
- **Predictive Analytics**: Usage trend forecasting, capacity planning, optimization suggestions
- **Reporting System**: Multi-dimensional data reports, visual charts, export capabilities

### 6. System Management
- **Device Management**: Hardware monitoring, firmware upgrades, fault diagnosis
- **Configuration Management**: System parameter configuration, business rule settings, customization
- **Backup & Recovery**: Data backup, system recovery, disaster recovery
- **System Monitoring**: Performance monitoring, resource usage, health checks

## 🛠️ Technical Architecture

### Hardware Stack
- **Main Controller**: ARM Cortex-A72 quad-core processor
- **Storage**: eMMC 32GB + external SD card expansion
- **Communication**: WiFi 6 + Bluetooth 5.0 + 4G/5G modules
- **Sensors**: Temperature & humidity, vibration, ambient light sensors
- **Actuators**: Electromagnetic locks, motor drivers, LED indicators

### Frontend Stack
- **Web Admin**: Vue 2 + TypeScript + Element UI
- **Mobile App**: Uni-app + uView + colorUI
- **Mini Programs**: WeChat Mini Program + Alipay Mini Program
- **State Management**: Vuex
- **Build Tools**: Webpack

### Backend Stack
- **Language**: Java 8
- **Framework**: Spring Boot 2.x
- **Database**: MySQL 8.0 + Redis 7.0
- **Message Queue**: MQTT
- **Cache**: Redis Cluster

### IoT Technologies
- **Communication Protocols**: MQTT + HTTP/HTTPS + WebSocket
- **Device Management**: IoT Hub + device registration + status synchronization
- **Data Collection**: Real-time data collection + batch data upload
- **Edge Computing**: Local data processing + cloud-edge collaborative computing
